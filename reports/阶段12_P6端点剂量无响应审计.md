# 阶段 12：P6 端点、剂量与身份契约无响应审计

审计日期：2026-10-15。建议状态：**`verified_pre_fit_without_external_response`**。这是对最终拟合前的字段、身份与剂量解释的验收建议，**不代表**最终模型、外验执行锁或 CTRP 成绩已经验收。本次只读取发布方字段说明、化合物元数据、冻结映射、清单、历史审计与策展代码；未打开 `v20.data.curves_post_qc.txt`、`ctrp_curve_index.csv`、任何 CTRP 响应值或外验结果。

## 可冻结的端点契约

1. CTRPv2.0 发布包的 `v20._README.txt` 将 `v20.data.curves_post_qc.txt` 描述为已做 QC 的拟合曲线 AUC、参数与区间；`v20._COLUMNS.txt` 把精确字段 **`area_under_curve`** 定义为 sigmoid 拟合浓度–反应曲线下的积分面积。这是**细胞活性/药物反应曲线的 AUC，不是 ROC-AUC**。`src/curate_ctrp.py` 和既有 `ctrp_curation_summary.json` 均指向同一原版字段，保留原值而不另作归一化。字段及版本可在最终拟合前固定；解盲程序只能按精确字段名取值，不能静默换成别的 AUC 或 IC50。
2. 该文件名的 `post_qc` 是**发布方已处理的数据层级**。已有整理未重做 raw-well QC 或逐剂量 censoring，亦未下载这些大表。因此 Methods 只能称“采用 CTRPv2.0 发布的 post-QC sigmoid 曲线 AUC”，不能称本项目重新执行原始实验 QC。`conc_pts_fit` 是实际参与拟合的点数，不保证每条曲线恰为 16 点；现有资格没有新增点数阈值。
3. 对同一 **CTRP compound ID × canonical cell / 独立生物组** 的多个合格 experiment，预冻结取 `area_under_curve` 的**中位数**，再以细胞/生物组计外验 `n`；experiment 不能当独立样本。冻结的 v2 primary manifest 共 1,185 个 drug–model 单位、1,201 条源 experiment/行指针，其中 16 个单位各有 2 条记录，最大重复数为 2；所有行均标注 `median_of_included_experiments` 和 `SNP-matched-reference`。源行指针及 experiment 数量在清单内一致；本审计未重新打开响应文件复核每个指针。既有 `src/validate_cohorts.py` 的历史独立验证包含 ID、细胞及 SNP 状态检查。
4. 若采用预测分数与 CTRP AUC 的药物内 Spearman 关联，**同一个固定的 CTRP 原版端点**须用于所有模型；方向解释只能作为拟合存活活性曲线的生物学**推断**，不可从字段名直接推出数值尺度或声称 GDSC/CTRP AUC 相同。不得按外验相关方向翻转标签或分数，也不得在两库原始 AUC 上报告跨屏绝对误差作为主要迁移结果。

## 八药身份及浓度核对

CTRP `v20.meta.per_compound.txt` 的 `master_cpd_id`、名称、`top_test_conc_umol` 与冻结的 `main_drugs.csv` 精确匹配；八个 GDSC ID 和八个 CTRP ID 均唯一。八条映射均在 `drug_identity_map.csv` 只有一条合格 `structure_supported` 边，完整 Standard InChIKey 与冻结记录一致。GDSC 官方药名经 PubChem 得到的结构同 CTRP SMILES 结构一致是**间接身份支持**，并非两库实际药瓶或批次的独立化学鉴定。

## 独立性与残余风险

- 冻结 v2 清单有 626 个开发生物组、175 个 primary 外验生物组；两者 canonical model 和 biological group 的交集均为 0。每药外验单位 82–169；这验证了当前清单的计算单位，并不保证新平台没有未发现的谱系、培养、测量或时间差异。
- primary 只纳入 `SNP-matched-reference`，`SNP-unconfirmed` / `SNP-not-tested` 留在敏感性集合；这是一项额外的保守资格条件，不等于证明被排除者错误。既有发布包/策展摘要显示原版曲线所有 AUC 可解析为有限值；本次没有独立重查响应表，解盲时仍须按冻结网关对非有限/无法追溯值作失败或 abstain，而非事后补选。
- CTRP 原版积分是否与 GDSC 的积分尺度、曲线拟合或剂量删点完全一致，现有无响应元数据不能证明。名义 top 的比较也不能恢复实际 post-QC 积分范围。若要统一积分窗口，必须另立终点版本、下载逐剂量数据和完整 QC 方案，并视为新的探索性分析；不能悄然改变已冻结外验终点。
- 八药映射未直接验证 GDSC 实物结构或药物批次。外验依然是跨药敏筛选迁移测试，不能从一次关联直接推断临床可转化性。
