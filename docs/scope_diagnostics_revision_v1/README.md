## 修改边界

- 研究范围限定为已评价的完整基因对编码与elastic-net流程；不称完整pair是天然不公平或不利测试，也不泛化到所有REO签名方法。
- 原主比较仍为响应关联pair200与MAD表达2000的实际管线比较；同候选规则、同200基因集合的比较继续为匹配表示比较。没有更改主终点、统计家族、药物或模型。
- 正文利用既有记录解释430/840零分子外层拟合、模型臂/药物异质性和内层选参路径。零解既不等于求解失败，也不证明生物学上无分子信号。
- Table 2只改变显示精度和真正相同预测的标注；机器表保留全精度。Figure 4A显示原34个有定义差值与46个NA，严格宏平均仍为NA。Figure 4B原估计、区间和样本数不变。
- 阶段7汇总误用repeat0的展示计数已修正；原拟合记录、S6与430总计没有变化，历史执行信息和修正依据分开保存。
- 英文作者事实、AI使用声明、31条参考文献与不可变发布/DOI保留；中文采用当前正式英文已经确认的作者声明事实。
