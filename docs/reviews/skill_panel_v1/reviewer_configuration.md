## 方法及限制

每个座位先在不读取稿件内容的独立调用上下文提交判据，再读稿审查；提交前不提供其他座位输出。角色分离不证明统计独立或错误独立。实际上下文、可见性、模型族/提供方和人工身份按观察记录，未知项不补猜。未获跨提供方传稿授权，不调用外部模型；评审未经金标准校准，标记`NOT_CALIBRATED`。

审查分别标明Critical、Major、Minor和非缺陷观察，不设问题数量或严重程度配额。每项须有位置、证据、理由与最小补救；未证实疑点列为待核实问题，不据疑点直接认定泄漏或结果错误。作者声明、归档和许可按既定收尾单列，不用来代替科学审查。
