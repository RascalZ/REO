本席按原有 D4 承诺检查概念可理解性、表示不变性与学习约束的区分、实践迁移边界以及跨领域延伸。材料足以辨认研究所比较的对象及证据能回答的问题，未发现达到预承诺 warn 或 block 阈值的 D4 缺陷。这里的通过仅针对本席维度；没有正式目标标准绑定，因此不形成正式期刊对齐结论，也不代替其他维度的审查。

### S1: 不变性的作用对象和成立条件表述清楚

**Evidence Anchor**: text: Background，第3段 — "applying the same strictly increasing transformation to every gene in a sample preserves its gene order."

该表述明确限定为同一样本内对所有基因施加共同严格递增变换，读者可以辨认保留的是基因间次序。文中同时说明幅度信息会被丢弃，并将这一数学性质作为开展比较的理由，而未用它证明学习后的预测在任意分布变化下保持有效。这满足相邻领域读者理解不变性所需的关键边界。

### S2: 表示所含信息与学习器能够利用的信息得到区分

**Evidence Anchor**: text: Methods，Candidate-gene selection and molecular representations — "their linear predictors and elastic-net penalties differ because the pair encoding expands that information into a larger, correlated feature space."; Discussion，第2段 — "The strong expression comparison tests the specified practical REO pipeline;"

主文明确指出完整秩表示和完整配对表示携带同一候选集内的次序信息，同时具有不同的线性预测形式和惩罚结构。其解释允许读者理解：配对展开可以改变模型使用次序的方式，并不增加新的测量信息。对 2,000 基因表达基线的实际流程比较、同一 200 基因集内的表示比较也有清楚分工；响应关联选基因使用连续幅度信息这一限制已明确披露。因此，结果被放在具体选基因及学习程序中解释，没有被提升为次序信息的一般优劣结论。

### S3: 组织基线与零分子解使分数的来源可解释

**Evidence Anchor**: equation: Additional file 14，SM4，y_hat = mu_y + s_y * [(z - d M) beta + d a]

补充公式及主文说明了零分子系数时预测如何回到已见组织均值或未见组织的总体训练均值。这个连接使药物反应研究者和机器学习读者都能理解，为何总体相关仍然存在却不意味着模型学得了分子特征。报告的零解数量、组织以上的描述性增量及表示间差值被作为不同问题呈现；非零系数也未被直接解释为生物机制。该优点是对稿件定义与报告关系的判断，本席未独立重算个体预测或系数。

### S4: 迁移任务的实际范围与未完成的外推得到明确区分

**Evidence Anchor**: text: Methods，Full-development models and locked CTRP v2 evaluation — "This analysis evaluates retrospective within-drug ranking transport from GDSC2 response labels to CTRP v2 response labels using the same CCLE expression source;"

主文反复保留同一 CCLE 表达来源、不同药物筛选及剂量窗口、非重叠生物组和固定模型这些条件。相邻领域读者能够理解，本轮考查的是回顾性的跨筛选药物内排序，而不能据此推断新表达平台上的稳定性、绝对 AUC 校准或患者结局预测。外部绝对相关、组织以上增量和 REO 相对表达的优势也被区分；完整预测覆盖仅被解释为既定推理规则可执行。LOTO 严格汇总未定义及条件区间不覆盖重新开发模型的不确定性均已显式说明，相关范围限制没有被隐藏为肯定的迁移结论。

### S5: 合成例子具有清楚的教学价值和证据边界

**Evidence Anchor**: text: Additional file 14，SM7.2，Predefined pair-order signal — "This deliberately places a response component in the ordering of two lower-variance driver genes."; SM8.6 — "They do not identify the cause of real-data zero solutions, establish a universal representation ranking, evaluate single-cell foundation models,"

共同幅度情景解释了次序表示可能丢失哪类信号，预定义配对情景解释了选基因与学习形式如何共同决定可恢复的信号。作者说明了配对驱动的刻意构造、强表达臂实际仅有 220 个可用基因、全部情景的保留以及描述性用途。由此，例子能够帮助跨领域理解机制上的可能性，却没有被用来分解真实药物结果的因果来源、估计真实数据零解的机制或代替真实标签的全流程置换。已披露的合成运行告警及环境记录限制需要保留，其存在本身不推翻这些受限的解释。

### S6: 与单细胞扰动领域的联系保持在可支持的层次

**Evidence Anchor**: text: Discussion，单细胞扰动模型段 — "The connection is methodological: the present zero-coefficient endpoint and drug-response task differ from deep-model mode collapse and perturbed-transcriptome prediction."

该段提供的是基线、系统性变异和预测目标诊断的共同评价思路，明确区分弹性网的零分子端点与深度模型的模式塌缩，也要求在虚拟细胞任务中直接验证后才能应用这些诊断。因而它构成可理解的跨领域讨论，没有把本研究包装为单细胞模型的实证评估。
