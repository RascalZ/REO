# 投稿前需作者提供或确认的信息

日期：2026-10-16。此文件只记录问题字段，不填写或推定个人事实。请在对话或私有副本中回复；未确认的姓名、邮箱、基金及机构意见不自动写入公开GitHub。本文仍为工作稿。

| 编号 | 请提供/确认 | 当前已知与边界 |
|---|---|---|
|A01|最终作者英文全名、顺序、共同一作/共同通讯安排（如有）、每人机构/部门/城市/邮编/国家；通讯作者姓名/机构地址/邮箱；投稿系统所需各作者邮箱。ORCID可一并提供。|不得沿用旧投稿自动推断最终顺序。AI不能署名；ORCID不是本次审查发现的普遍强制门槛。|
|A02|每位作者对研究、最终稿及投稿的同意；稿件是否与已发表文章/会议摘要/预印本重叠，若有请给标识和说明。|已有会话记录称旧投稿均已拒；无需重述拒稿史。实际提交当天仍要确认无一稿多投，并由列名作者提交。|
|A03|本次公共细胞系二次分析适用的伦理说明：不适用及依据，或真实批准/豁免机构、编号和日期；是否包含可识别个人资料、需要发表同意的内容。|现有研究材料是公共细胞系数据；不能由此替作者或机构宣布豁免。若确实不适用，保留相应标题并用有依据的简短说明，不要求无依据新增IRB申请。|
|A04|全部基金名称、项目号、资助对象及资助方在设计/分析/写作/发表中的角色；若无专项资助，请确认。|不能从未提供基金号推断“无资助”。|
|A05|全部作者的财务及非财务利益冲突；若均无，请明确确认。|不能自动填写“无利益冲突”。|
|A06|每位作者的实际贡献：问题/设计、数据整理、方法/代码、验证、分析、可视化、写作、修改、监督、经费等；谁负责核查模型和科学解释。|可用CRediT帮助整理，但不要求为每人凑齐角色。科研判断与责任属于人类作者。|
|A07|需要致谢的非作者及其同意；若无，请确认。|不得未经本人同意列出致谢人。|
|A08|核实AI实际用途、工具/服务名称、使用日期及可确定的模型/版本；确认作者如何检查代码、结果、引用和文字。|本项目的Codex辅助涉及方案讨论、代码开发/排错、分析核查、图表脚本、文献与写作，不能仅写语言润色。未知历史模型版本如实说明，不能编造；稿件Methods及需要的AI Declaration均须与实际一致。图件来自可核验聚合数据的代码绘制；是否需相应图例说明按实际AI用途与最终政策核对，不把代码辅助误写为经验数据由AI生成。|
|A09|数据/模型对编辑、审稿人及读者的获取方式，是否有机构或数据提供者限制；若限制，谁处理申请、按什么条件提供。|先由助手整理本地最小复现资产和上游来源，再由作者确认公开/受限范围。不需要上传账户密码或凭证，也不需把全部原始大矩阵塞进仓库。|
|A10|归档记录的真实作者/贡献者、拟发布版本、发布归属及持久标识；若已有Zenodo等归档，请给记录链接；若无，后续在发布包定稿后创建。|代码已是MIT，无需重新选择代码许可。档案应绑定tag/commit；DOI是推荐方式，非唯一允许标识。现在不能凭空填写DOI或把GitHub主页当归档DOI。|
|A11|文章开放许可是否受基金/机构要求约束；在期刊可用的CC BY 4.0与CC BY-NC-ND 4.0中确定适用选项。确认第三方内容引用/再用条件。|文章许可、代码MIT和上游数据条款是三件事。2018 CCLE表达不自动继承DepMap 24Q4元数据的CC BY；原始矩阵再分发条款未确认前不打入MIT发布包。|

可直接沿用的事实：研究使用现有公共数据；新重构代码已有MIT许可；八药、模型和统计结果不因投稿整理而更改；CTRPv2已经执行一次，不能再用来调参。仍需作者通读全部最终引用来源并批准最终论文。
