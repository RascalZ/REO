# Published-asset wording for the next manuscript copy

These statements describe the real 27 October 2026 publication. They are
prepared for author review; the preserved v4 manuscripts and submission ZIP
have not been modified by the software release.

## Availability of data and materials — proposed replacement

Source code, frozen model parameters, candidate-gene and coefficient tables,
original fold assignments, minimal identity and drug-membership projections,
and response-free inference examples are available in the REO repository
(https://github.com/RascalZ/REO), release v0.1.0, and archived at Zenodo
(https://doi.org/10.5281/zenodo.23681422). The archive includes per-file
checksums and preserves zero-coefficient model solutions. The original
expression and drug-response datasets must be obtained independently from
their source providers under the applicable terms, as detailed in the
repository's data-availability documentation. Individual external response
values, source response indices and individual external predictions are not
redistributed. The minimal metadata and frozen-model inference package do not
constitute the complete inputs for every historical curation and external
rescoring step.

## Code and asset licenses — proposed replacement

Newly authored code is released under the MIT License. Author-owned model
parameters and derived research assets are released under CC BY 4.0 to the
extent that the authors hold the applicable rights. These grants do not
relicense third-party datasets, annotations or identifiers; source-specific
terms and attribution remain applicable.

## Citation boundary

The Zenodo DOI identifies software and research assets. It must not be
described as a DOI for the manuscript. Release creators follow the confirmed
eight-author v4 order. The actual GitHub release, immutable tag and source
commit are recorded in PUBLICATION_STATUS.json. Manuscript authorship
approval and missing declaration facts remain author responsibilities; this
release does not assert journal-submission approval by every author.
