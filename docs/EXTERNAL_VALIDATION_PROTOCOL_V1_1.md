## 问题、端点和不可变面板

主问题是在开发集中**从未出现过的细胞模型生物组**上，固定 GDSC2 模型的 REO pair 是否比强表达 EN 更能预测 CTRPv2 同药物 AUC 的**组内排序**。两套药敏筛选共享 CCLE 表达，故不评价跨表达测量平台；细胞系排序迁移亦不等于患者疗效或临床应用。所有八种药物、八个模型臂、癌队列 v2 的身份/亲缘组/来源筛选和原定药物剂量资料均沿用锁定版本，不按开发或外验分数删除、替换或重排。[队列锁](../config/cohort_freeze_v2.lock.json)和[面板元数据](../results/cohort_v2/main_drugs.csv)是唯一映射依据；后者 SHA-256 为 `5704749a9b416b920f5028703e2b578aedf3dbe07a0ab8d500f4ff9f2fbbc1b6`。v2 当前为 626 个开发独立生物组、175 个主外验组；药物×模型观测分别 4,967 和 1,185，不能累加成独立样本数。

## 固定的 8×8 全开发拟合矩阵

每一格必须执行且保留，**不是**根据既有结果筛选胜者。固定的两个候选规则（训练内 MAD200、响应关联200）、三种表示（连续 log 表达、样本内秩、完整三值 pair）、2000 基因强表达与同政策组织参照，均沿用[新版八药算法](../docs/ORDINAL_REPEATED_V1_PROTOCOL.md)及其[模型配置](../config/ordinal_repeated_v1.json)；旧正式 v1/RF 结果只作历史背景，不进入本次模型选择。没有外部标签、外部响应分布或外部表达分布参与候选筛选、参数选择或拟合。

合计 8 药×8 臂＝64 个任务；每药七个分子臂各 `10 候选×3 内折+1 次全开发重拟合=31`，加组织参照 1 fit，预计 `8×(7×31+1)=1,744` 次 fit。该数是设计预算，任何失败、资源暂停、重试另记，不减写已成功任务。采用与开发评价相同的 `make_grouped_splits`：全部 626 个开发独立生物组按组织分层生成一份共享 3 折，种子 `2026101501`，按每药合格组取交集；所有八臂共用。每候选每内折重做检测、候选选择、表示、标准化、组织 FWL 与 alpha_max。EN 候选固定为 alpha_max 比例 `[1, .3, .1, .03, .01]` × L1 比例 `[.5, 1]`；以合并内折 OOF 的原 GDSC AUC 单位 RMSE 最小选参，精确并列取第一候选。ratio 1 的解析零分子解是合法模型；训练响应或可选特征退化按既有同政策回退记录。最后用全部该药开发组按选中参数**重新拟合完整管道**，不以开发外折最优模型对象充当最终模型，不按 CTRP 性能换配置。

全开发模型预计串行 64 个任务、1,744 fits；先单任务资源探针，再按现有单 worker、BLAS 线程 1、任务独立进程及 checkpoint 规则运行。此前 LOTO 任务的 RSS 峰值不能充当全开发任务的准确内存上界；本阶段估时和峰值须由无外验响应的初始 fit 记录更新，资源不足时暂停保存检查点，不换八药/八臂或搜索网格。模型 artifact、特征及审计留在受控本地目录，公开仓库只放非敏感汇总与可复现来源哈希。

## 最终模型与无响应输入网关

每格保存可重载模型及独立审计：开发样本/组身份哈希、原表达来源及完整 stable Ensembl ID 列序哈希、选中 gene IDs 按 stable ID 升序、pair 方向和全部列序/哈希、候选/内折分数、超参数、scaler/目标/组织 FWL 状态、零分子标志、软件环境、源码与输入 SHA-256。joblib 只加载本机受信任的已哈希 artifact。新进程重载后用开发或合成哨兵样本检查已知/未知组织、pair tie 与零分子预测；相同顺序下绝对误差≤`1e-12`、相对误差 0，否则不开闸。不可从旧 OOF/checkpoint 猜造最终部署模型。

网关先验证冻结 compound/canonical 模型映射、主外验成员、与所有开发及已知候选亲缘组零重叠、表达版本和列序。映射冲突、重叠、来源/模型哈希、**完整预期基因列缺失/多余/重排**、端点字段或剂量契约不符为**硬失败**，停止整次评价；不能以局部弃判掩盖协议错误。每条预定药物×模型行保留在原资格分母中。缺失组织或非法组织值使该行所有臂无预测；**合法但训练未见的组织**可预测：组织参照用训练总体 AUC 均值，分子模型的未见组织项为 0，仍保留分子项，并标记来源。

目前已实现的七个分子特征器要求**完整、有限、非负 float64 的原始 TPM 全输入向量**。完整列 schema 已验收后，某个样本中任一基因值缺失/非数/非有限/负值，使该样本七个分子臂弃判；不以训练中位数、外验众数、零值或 pair tie 填补。整张表缺列/多列/重排列序属于结构性错误，按前述硬失败处理，不伪装成所有样本的普通缺失。旧总计划 §4.5 的低缺失填补只是早期建议，不适用于已冻结的八臂实现。即使分子弃判，只要身份与组织有效，`tissue_null` 仍可预测；实现可用不参与分子计算的占位载体调用组织参照，但不得把该占位视为表达填补。**零分子系数不是弃判**，需保留其预测及标志。模型输出非有限、重载不一致则为硬失败，不按分数重跑。网关必须以纯合成或开发输入测完这些分支，不能用 CTRP 数值试规则。

逐药报告锁定资格 N、实际响应有效 N、八臂各有效预测 N、每个配对共同 canonical ID/独立组 N、因身份/组织/TPM/模型/标签造成的每种未覆盖原因，以及未知组织和零分子数量。不能把重复曲线或八药同一细胞重复计作独立组；也不能只报成功预测的 N。任何对比两臂必须用**同药、同一 canonical ID、同一聚合 CTRP 标签的共同集合**分别算相关，再做差；各臂自己的最大覆盖相关另列，不与不同样本集的相关直接相减。

## 一次性外验估计量和区间

主点估计逐药为 `ρ(response_association_pair_full) − ρ(expression_strong)`，其中两项都在该药的共同 ID/组上计算。Spearman 至少要 3 个不同生物组，且原始方向响应和每个预测均非恒定；否则对应相关及配对差记 **NA + 明确原因**，绝不改记 0。设计原偏好单药至少 80 个外验组；共同覆盖 `<80` 时，若相关有定义仍保留描述性点值，但标注低于设计覆盖，不能写强迁移结论。八药差的严格等权平均是主宏值；**任一预定药物主差 NA，则主宏 NA**，不得用 `nanmean` 或删掉困难药重算。零分子、组织参照在同一组织内恒定、失败和极差结果都要保留。

主检验族固定 9 个估计量：八药逐药主差 + 严格八药宏差。单独的解释族固定 18 个：MAD 和响应关联规则各自的 `pair_full − 同候选 expression200`，各自八药 + 八药宏；rank 臂仍展示，但不新增推断族。若部分估计量为 NA，家族原规模仍为 9/18，不能缩小调整分母。其他臂对组织参照、rank 对表达/pair、组织分层、每药异质性、覆盖和零解只做描述；不以外验结果增删主/解释比较，也不把“无显著差”说成等效或非劣。

固定模型的置信区间使用 `20,000` 次共同生物组 bootstrap，种子 `2026101502`。每次从锁定的 **175 个外验独立生物组**有放回抽取 175 次，形成一份共享 multiplicity 向量；所有药物、臂和对比共用这一向量，再在各药已定义的共同集合内按相同权重复制标签与两臂预测，重新计算精确带并列 midrank 的 Spearman、配对差及严格宏。保存组顺序、权重矩阵哈希、库版本与每个估计量的无效 draw 原因。每估计量至少 `19,800/20,000` 个有效 draw 才报 percentile CI，否则区间 NA；不得重新抽到够数、只留有利药或用可用格代替宏。未校正名义 95% CI 仅作描述；主族名义家族 α=.05 Bonferroni 端点分位为 `.05/(2×9)` 与其对称上端，解释族为 `.05/(2×18)` 与其对称上端，插值 `linear`。两族分别控制其**名义条件区间**，不宣称合并全研究覆盖；20,000 draws 的极端尾端仍有 Monte Carlo 精度限制。若点估计本身 NA，则 CI 必为 NA。

这些区间条件于已经拟合好的固定模型及回顾性测试群体抽样，**不覆盖**开发数据的特征筛选/调参/重拟合变异、历史 CTRP 接触、药物作为总体随机抽样或患者临床外推。外验主证据是源间排序关系的可迁移性及 pair 对强表达的配对增量；既有内部负面结果与外验结果必须并列报告。如果主宏 NA 或效应不支持优势，不能事后改用表现最好的药、rank 臂、不同方向或跨库 RMSE 作为“主成功”。

## 执行顺序与最终冻结门槛

1. **无外验响应证据核验：**根据官方来源文档、既有冻结策展代码及元数据，核定拟用 CTRPv2 post-QC AUC 字段、重复实验中位数政策、八药 compound/结构/浓度摘要、表达源版本与队列身份/亲缘组锁；此时不打开响应文件或响应索引，也不看数值。把上表浓度差写入最终报告，不作事后同窗改造；不依外验标签相关决定 AUC 方向。
2. **网关、统计和合成契约：**实现并测试完整/缺失/非有限/负 TPM、全局缺基因、合法未知组织、缺失组织、真实 tie、零分子、常数预测、重复/冲突身份、共同 ID、严格宏、共享组 bootstrap 和硬失败；无响应即可检查分母及原因。固定整个统计方法与种子，不能到模型/外验成绩出来后再修订。
3. **第一道锁（拟合前）：**上述证据与合成测试全部通过后，保留原 `config/external_validation_v1.lock.json` 不变；从新版本配置、协议、guard、审查及验收生成独立不可变的 `config/external_validation_v1_1.lock.json`，绑定本协议/配置、全部训练与评分统计源码、开发输入、前身锁和环境。**必须先有v1.1科学锁，才可进行任何1,744次设计内拟合。**
4. **全开发拟合：**仅按第一道锁执行固定 64 任务；保存全部 1,744 预期 fit 事件、失败与资源记录。独立验证 626 开发组内折无亲缘跨折、三折覆盖、每 fit 特征只由当前训练行估计及八臂/八药无遗漏。
5. **重载和第二道锁（读外验前）：**新进程重载全部模型 artifact，哨兵预测一致；另生成 `config/external_execution_v1_1.lock.json`，状态 `frozen_pre_external_response`，绑定**不可变的v1.1第一道锁**、64个artifact/特征/输入SHA-256和实际评分代码，完成独立无响应预检。此时不改第一道锁所绑定的协议/配置/统计方法；如发现科学契约错误须另版重来，记录发现时已见何种结果。第二道锁通过前仍不能读CTRP响应或索引。
6. **一次性 CTRP 评价：**从冻结主外验集合读标签、按源规则合并实验、运行全部八药八臂，输出逐行原因/覆盖、逐药与严格宏、两个固定区间族及失败清单。完成后不因表现修改规则；受控工程异常只可显式 `--resume` 同第二锁重放并保留原失败记录。进程硬中断而只留 `started` 记录时，必须使用显式 `--resume-unclean`，核实同锁、同主机旧 PID 与创建时间所标识的进程已停止且不存在成功结果；保留旧 marker 并追加 `unclean_abandoned` 审计记录。不能并发重放、删改旧记录或借恢复更换模型/统计。

**门槛状态：**字段、post-QC 和重复中位数政策、八药 compound/剂量元数据、网关和统计合成测试及独立代码审查已完成无响应验收。第一道锁仍需已提交源码快照、`--ready`、`--lock` 和 `--verify-only` 实际成功。第二道锁之前还须有64个完整最终模型、1,744预期 fit、训练来源与独立重载审计，以及模型 artifact、实际评分源码和9,480条无响应预测预检的锁定。**在第二道锁通过之前，CTRP 响应与索引保持封存。**
