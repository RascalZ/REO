# Publication input and identity audit — v1

Audit date: 2026-10-16. Scope: local technical preparation under master plan v3.36. This document describes the frozen study; it does not authorize another training run, external scoring, identity amendment, source download or source-data release. The accompanying [input inventory](input_asset_inventory.csv) records relative asset names/configuration keys, roles, existing hash records and local/access status. Original inputs and earlier outputs remain unchanged.

No CTRPv2 response table, processed response index, legacy four-column CTRP response table, individual external prediction file, bootstrap sample file or trained-model payload was opened for this audit. Expression matrices were not loaded or rehashed. File existence checks are not content verification; hashes in the inventory are copied from existing provenance records, not a new end-to-end data validation. No numerical response values are copied into this package.

## 1. Four different dependency questions

| Purpose | Minimum functional inputs | Boundary |
|---|---|---|
| Demonstrate prediction without external labels | A frozen portable model/preprocessing export, its ordered gene schema, valid new nonnegative finite TPM and a tissue label, plus nonidentifying row IDs | No training labels, CTRP response, historical CTRP bridge, old four-column table, source workbook or complete original metadata are mathematically needed. The demonstration must identify synthetic/example inputs as such and must not claim external validation. |
| Reconstruct final training numerics | Prepared GDSC2 `development_responses.csv`; frozen raw CCLE TPM; ordered gene table; final shared inner-fold identities; fixed eight-arm configuration and fitted-preprocessing code | This describes dependencies only. Do not rerun the completed final training. The 19,836 protein-coding columns and development row indices are selected from the frozen source schema, rather than substituted with a newer DepMap expression release. |
| Execute the original final-training controller faithfully | All numerical inputs above **and** the precise first lock, execution Git source, predecessor locks/configurations/protocols, cohort manifests, source provenance and hash-bound metadata | The frozen controller verifies the entire first-lock `files` dictionary plus selected cohort-v1/v2 dependencies. Some dependencies are checked for integrity, not passed into the regressor. A clean inference export must not be confused with replaying this controller. |
| Reproduce every historical source/identity audit | Exact source releases, historical annotation and name bridge, source indexes and original input provenance; some early scripts also open the old CTRP four-column table and archived CTRP curves | This remains broader than final-model inference. Running these scripts would violate the present response seal. No public-data-only replacement has been installed or certified by this audit. |

The final worker's numerical path is explicit in `src/run_final_model_v1.py`: `_response_source_verified` checks the prepared responses saved by `runs/gdsc2-cancer-v2-fixed8-nested5x3-inner3-formal-v1/formal_metadata.json`; the controller copies that same file to the final run. `load_drug` sorts the selected drug's records by canonical model ID, reads `expression_genes.tsv`, selects explicit `protein_coding` rows, maps `expression_row_index` into `expression_tpm.npy`, and reads the prepared GDSC `response_auc`. The worker uses the saved `global_inner_fold_manifest.csv` and intersects it with that drug. It does **not** reread the source GDSC workbook, historical cell-name bridge or legacy CTRP table as predictor/response input.

`verify_development_inputs('v2')` nevertheless verifies both cohort freezes and their parent relation, the development and drug manifests, TPM/gene/sample tables, cell dictionary, source-SHA register and `project_paths.py`. `verify_freeze` additionally hashes every file bound by `config/external_validation_v1_1.lock.json`. The historical formal metadata and source response copy are therefore real local prerequisites of the original controller, not optional narrative references. Existing source files are not silently regenerated if these checks fail.

## 2. What is current, historical or optional

The current scientific cohort is **v2**, with 626 unique development models/groups, 4,967 drug–model observations, 175 primary external models/groups and 1,185 external drug–model observations. The public snapshot is `results/cohort_v2/public_cohort_snapshot.json`; the freeze's pre-validation status text is a historical snapshot, with its validated state recorded by `config/cohort_freeze_v2.lock.json` and the public snapshot. Counts must not be taken from old cohort-v1 manifests or added across drugs as independent sample sizes.

Current modeling uses **raw float64 historical CCLE RSEM TPM 20180929**, transformed within the model as required. `expression_log2tpm.npy` is an audit by-product, not the raw numerical input read by the final worker. Counts, the historical count-copy comparison and annotation header checks support the original input audit; DESeq2/raw-count modeling is not part of the final EN regression study. No recent DepMap expression is mixed into the 2018 matrix: DepMap 24Q4 Model metadata supply identity and disease/tissue evidence only.

The GENCODE19 GTF is used during annotation preparation. Exact full versioned Ensembl IDs are matched first; only explicit protein-coding entries enter modeling. Stable IDs are recorded after removal of a terminal numeric version, with uniqueness checked. The matched GTF hash is in the inventory. Unmatched annotation entries are not silently labeled noncoding, averaged or mapped by gene symbol. A minimal replay must preserve both matrix column order and the versioned-to-stable mapping; a list of symbols alone is insufficient.

Original compatibility inputs serve specific roles:

- `legacy_cell_annotations`: historical exact CCLE accession/ACH and primary-site evidence used by `curate_cells.py` and `map_ctrp_cells.py`.
- `legacy_ctrp_bridge`: supplemental exact normalized CTRP-name-to-CCLE evidence in `map_ctrp_cells.py`; a bridge-only candidate is not sufficient for acceptance.
- `legacy_ctrp_response`: `curate_drugs.py::extract_local_inventory` historically opens it to count drug names/rows. The function documents that it does not convert/use AUC values, but the file physically contains responses. It is **not** safe to run now. It is not a numerical input to the frozen final worker.
- `legacy_project_counts`, `ccle_counts` and `ccle_annotations`: historical source/header/compatibility audit inputs. Their exact source facts and hashes remain part of provenance even when the final worker does not consume them.

The complete historical `validate_cohorts.py` also opens archived CTRP curves to verify source-row links and response availability. It is not an appropriate publication-preparation validator while labels remain sealed. Similarly, rerunning `freeze_cohorts.py` against an existing freeze can hash all frozen dependencies, including response-bearing files. Inspect the inventory/protocol and existing aggregate validation records instead of invoking these entry points.

Independent expression-platform data, PRISM, new GEO/single-cell data, FASTQs and common-dose curve reintegration are not current minimal inputs. No such extension is represented as completed evidence or a prerequisite for this no-label inference example.

## 3. Minimal identity schemas

These are field contracts to export after provenance and redistribution review, not a claim that all upstream tables are already public. Store IDs as strings; do not remove meaningful prefixes, infer a model from a display name, or replace unresolved IDs with nearest aliases. A dataset-specific raw row number is meaningful only together with its exact source file hash.

| Table | Minimal fields | Constraints/use |
|---|---|---|
| Expression row identity | `expression_row_index`, `ccle_id`, `canonical_model_id`, `biological_group_id`, `tissue`, `mapping_status`, `mapping_evidence`, `expression_eligible` | Zero-based raw NPY row; accepted canonical IDs unique; preserve exact accession and evidence. Use the cohort-v2 tissue field for this paper. |
| Expression column identity | `expression_column_index`, `gene_id_full`, `ensembl_id`, `gene_type`, `annotation_exact_version_match` | Zero-based raw NPY column; exact order/versions; unique stable IDs in the modeled subset; 19,836 explicit protein-coding columns. Symbols may be an annotation, not a join key. |
| Biological grouping | `canonical_model_id`, `biological_group_id`; separate edges `model_a`, `model_b`, `relation`, `source_id` | Preserve known relation graph and evidence, not just a freshly invented cluster label. |
| Development membership/assay | `gdsc_drug_id`, `canonical_model_id`, `biological_group_id`, `ccle_id`, `expression_row_index`, `tissue`, `gdsc_source_row_number`, `nlme_curve_id`, `min_conc`, `max_conc`, `role`, `cohort_version`, `eligibility_status`, `evidence_source` | The current source manifest has no response column. It identifies which GDSC response to retrieve for historical reproduction; do not add values to a public identity-only export. |
| Drug identity | `primary_drug_rank`, `gdsc_drug_id`, `ctrp_compound_id`, names, full structure-supported InChIKeys, `match_status`, `match_evidence`, exact GDSC dose bounds, `cohort_version` | Keep assay-specific IDs distinct. Structure support is from source SMILES/name resolution, not independent chemical authentication of assay bottles. |
| Cohort role/eligibility | `canonical_model_id`, `biological_group_id`, `global_role`, selected-role flags, `eligibility_status`, `included_v2`, `exclusion_reason`, `evidence_source`, `v1_tissue`, `tissue`, `cohort_version` | Preserve excluded and unresolved categories; avoid publishing upstream patient/sample IDs unless required and reviewed. The internal source manifests contain more metadata than this minimal contract. |
| Final inner folds | `canonical_model_id`, `biological_group_id`, `tissue`, `inner_fold`, `role` | Global 3-fold definition shared by drugs; train/validation membership intersected by drug, with no biological-group overlap. Fold definitions are identity-only and do not need response values. |

The external primary manifest is a frozen **identity/source-pointer** contract, not an external label table. It records drug/model identity, experiment/master-cell IDs, source row references, SNP-QC status, future median aggregation and role. Its source pointers need not be distributed with the synthetic inference example. No external identity or source-row data are copied by this audit; keeping the original manifest sealed against amendment protects the completed analysis. External sample membership alone does not make the retrospective study prospectively blind.

## 4. Identity and grouping boundaries

`curate_cells.py` combines exact Broad/CCLE/Sanger/COSMIC cross-references and accepts one canonical candidate. Ambiguous, unmapped, conflicting and duplicate-expression-model records are excluded; known candidate IDs are retained for exclusion auditing. The CTRP mapper compares exact names after case/punctuation normalization, uses corroborated named accessions, and checks primary site when both sources provide it. It does not do fuzzy nearest-name matching; missing site metadata is recorded, not called a confirmed match. GDSC IDs and named CTRP accessions must therefore not be treated as the same type of evidence.

Biological groups are connected components under recorded Broad PatientID same-tissue-sample links, Sanger same-patient links, parent/derivative links and multiple Broad IDs connected to the same Sanger model. Broad PatientID is not a complete donor genealogy. Unknown relatedness can remain. The fact that the selected v2 cohorts each have one model per group does not justify discarding the group mapping: exclusion was applied against **all known GDSC2 candidate groups**, including unresolved identity candidates and unselected drugs, rather than only the final eight drug-specific samples.

V2 applies a metadata-only cancer-eligibility overlay after the development pilot, before the reconstructed external response access. Explicit `Non-Cancerous` is excluded; absent/Unknown disease is quarantined unless exact authoritative evidence supports an exception. The documented HCC1588 exception is bound to ACH-001078 / CVCL_A351 / SIDM01820 / KCLB71588 evidence. This amendment is not pre-pilot preregistration. Tissue canonicalization changes capitalization by exact casefold correspondence to the authoritative vocabularies; it does not merge histologies or guess tissue from a name.

The primary external cohort requires recorded `SNP-matched-reference`. SNP-not-tested/unconfirmed records are separate sensitivity candidates, not proven misidentifications and not additional evaluated primary cases. The drug panel and ordering were retained through v2. Minimum 200 development and 80 primary external groups are feasibility rules, not a power guarantee.

## 5. Local readiness and remaining integration

The inventory separates `tracked` repository files from local ignored assets. It does not copy matrices, annotation tables, patient/sample links, legacy originals or response-bearing data. Public URLs are source locations previously recorded by the project; availability was **not** freshly verified over the network. Historic API snapshots and derived identity manifests require an actual accessible release or clearly specified restricted route before claiming end-to-end third-party reproduction.

For the next integration step, export the minimal development identities/folds and trained feature/preprocessing/coefficient schema through a deterministic, explicit allowlist; bind every export to the source hashes and avoid patient/sample-source fields that are unnecessary for prediction. Verify the no-label example using synthetic expression/tissue inputs and frozen exported coefficients only. Keep these three claims separate: (1) a runnable synthetic-input inference demonstration, (2) complete portable trained-model prediction replay, and (3) full public-source rebuilding of all historical curation. Passing (1) alone does not establish (2) or (3). Formal author statements, artifact hosting and upstream redistribution decisions remain deferred to the final publication gate.
