# P5e组织分层OOF相关指标澄清 v1.1

日期：2026-10-14。此文件是P5e协议v1的窄范围统计澄清，不重写或删除协议v1、阶段8产物、固定八药OOF或阶段6主分析。它在组织残差对比重新汇总前冻结；CTRP仍禁读。

## 原因

阶段8的绝对组织内OOF相关为`Spearman(y, prediction)`。每个已知组织的5折外层预测由不同训练折产生，`tissue_null`在不同折的训练组织均值略有差异。同一组织的测试行因而包含多个折特异常数基线；按绝对预测算的组织内ρ可受到这些折间均值偏差影响。阶段8已经把null绝对ρ标为诊断量，但阶段8及8a对候选与强表达模型的Δρ仍直接相减绝对相关，不宜作为“组织null以上分子增量”的主估计。

## 冻结的校正指标

在同一药物×组织×repeat的相同完整OOF行定义：

- `e0 = observed_auc - tissue_null_prediction`，即组织参照残差；
- `q_m = prediction_m - tissue_null_prediction`，即模型相对组织参照的分子预测分量；
- `rho_residual_m = Spearman(e0, q_m)`；
- 配对增量`Delta_rho_residual(A,B) = rho_residual_A - rho_residual_B`，同一测试成员，A与B均须可定义。

主展示集合维持原冻结10种共同组织，全部23种组织逐格保留。每个组织先单独计分，然后组织等权汇总到药物×repeat；固定八药再等药权汇总。严格汇总只在全部预定组织/药物格定义时给数值，同时报告可定义格数和可用格描述均值；strict缺失记NA，不用`nanmean`替代strict值。常数`e0`或`q`、有效样本少于2及非有限值均使该相关NA；不填0、不删除组织、不选择性改换药物。

预设对比包括：响应关联完整pair−强表达2000、响应关联完整pair−同候选表达200、响应关联完整pair−同候选rank200、响应关联完整pair−MAD完整pair。其他候选/表示的单臂`rho_residual`照常保留，便于判读候选政策和表示差异。paired RMSE仍为`RMSE(reference)-RMSE(candidate)`，沿用阶段8源数值，不受本相关指标澄清影响。

阶段8和8a中的绝对`Spearman(y,prediction)`及其差值保留作“包含外折组织均值波动的绝对预测诊断”；不称为组织内个体分子增量，不删改原始报告。相关估计、宏均值和三repeat范围均属描述；不新增CI、P值或确证性检验，不把repeat视作独立样本。

## 对LOTO的影响

在LOTO的一种被留出组织内，该外折`tissue_null`对所有留出样本是同一个训练总体均值，因此减去该常数不改变相关系数的秩。此时`Spearman(y, prediction_m)`等于`Spearman(e0,q_m)`（仅受浮点数值误差），所以LOTO原先的单组织相关估计目标不变；报告统一称作组织参照残差相关，并继续将组织null相关记NA。所有outer/inner划分、调参、模型及任务数量不变。

本修正源自分折组织null在重复OOF内变化这一估计目标属性；它不依赖方向或数值大小，不能用来挑选更有利于REO的指标。v1绝对rho诊断和v1.1残差增量同时归档，清晰区分后继续原序列。
