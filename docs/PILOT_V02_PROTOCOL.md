# 队列v2、REO200与RF试跑协议

声明日期：2026-10-12。首次真实模型拟合前写定；原v1和v0.1试跑保留。总计划的唯一维护入口为`RESEARCH_PLAN.md`。

本轮仍是两药开发专用试跑：MIRA-1（625个癌模型）及PLX-4720（622个癌模型），固定面板不按成绩调整。v2全局开发模型626个，外验175个；非癌控制排除，HCC1588的精确权威癌模型证据核实后纳入。CTRP响应继续禁止读取。

|模型|表示/组织政策|内层候选数|
|---|---|---:|
|训练均值|当层训练均值；相关记NA|不调参|
|组织Ridge|训练fit完整OHE，未知组织回退全局均值|6|
|强表达EN|训练MAD前2000基因；标准化后FWL组织项不惩罚|10|
|匹配表达EN|训练MAD前200基因；与REO200的基因预算匹配|10|
|REO EN|200基因最多19,900原TPM排序对；标准化后FWL|10|
|强表达RF|训练MAD2000基因原logTPM + 同一训练OHE|6|
|REO RF|训练MAD200基因原REO；训练内控制组织的Pearson筛最多500对 + 同一OHE|6|

EN路径为相对`alpha_max`的1/0.3/0.1/0.03/0.01，L1比例0.5/1；每次fit由该训练子折的标准化/FWL残差重新计算最大梯度，不借用整外层训练或持留标签生成路径。比例1包含分子零系数解，选择该端点不自动意味着还需要更强惩罚。solver最多4000迭代、tol=0.001；保留警告、dual gap、实际alpha和非零系数。RF固定300树、单线程、固定seed，max_features=sqrt/0.1及leaf=1/5/10。RF组织项仅为协变量，不能据此宣称完全消除组织混杂。

外层3折一次、内层3折，全部模型共享全局已知生物组/组织划分；仅在药物可用样本上取交集。保持原AUC尺度合并内层OOF RMSE选参和固定并列规则，外层结局最后用于评价。预算906次主试跑拟合、8,729条OOF预测；另外8次训练专用预算探针分别标记，不纳入性能比较。

资源预检使用首外层/首内层训练成员：弱端EN ratio=0.01且L1=0.5，RF max_features=0.1/leaf=1。仅拟合测时、内存、收敛，不计算持留成绩或选模型。主运行单进程/BLAS单线程、100ms RSS采样、每外层模型检查点、异常资源收尾。正式8药5×3重复与统计推断不在本轮范围；不能按REO是否获胜判断工程验收通过。

主要比较是同ID的REO EN200与表达EN2000；RF的架构内比较为辅助。报告逐药OOF Spearman/RMSE/R²、逐折变化、组织基线增量、n≥20组织内描述、非零分子系数及资源。没有确认性P值、等效/非劣声明；目前不宣称可靠优势。新旧试跑同时改变队列、划分、基因预算和正则路径，不能将新旧差异归因于200基因单一因素。

癌队列v2仅冻结科学数据资格/身份；本模型配置和实现以运行前Git提交、配置/源码hash记录。完整输入、单样本预测和每折特征留本地，聚合结果、来源证据与审计代码同步GitHub。
