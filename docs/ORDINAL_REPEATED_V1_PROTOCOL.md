# 固定八药：两候选规则×三表示的重复嵌套评价协议 v1

## 问题与可支持主张

问题按层次预设：在固定候选规则和评价条件下，分子表示是否具有组织均值以上的增量；同候选集的表达200、秩200与完整pair是否有不同泛化表现；新REO流程相对表达2000 EN是否有可靠增量。不能以部分药物、单指标点排名或非零系数替代这三个问题。

四药阶段5只能描述：在结果启发案例、连续log表达—响应关联候选及3折×1次流程中，三个案例的样本内顺序表示观察到组织以上的排序增量；该增量也见于表达及秩，不是REO独有。Tamoxifen三臂3/3零解、真实标签26/72分子拟合零解及条件OOF区间必须共同陈述，不能一般化为所有药物或稳定标志物。

REO不增加测量信息，仍可能通过归纳偏好、模型可表达关系、正则化及对特定扰动的敏感性影响有限样本学习。完整三值pair与固定基因集平均秩承载相同序信息，但线性秩的pair权重受基因系数差约束，EN惩罚不等价。表达→秩→pair的差异不能直接分配为幅度、维度、共线性与惩罚的因果损失。当前候选关联规则基于连续表达，对表示并非中立；共享基因不消除筛选目标与表示的交互。

非劣性只列待独立论证的预测性能保持问题；不采用−0.02或任何数值界值，不作非劣/等效检验或结论。未来须先明确参考、容忍损失依据、估计目标、检验族及区间方法；性能非劣也不能证明保留全部信息，更不能将两臂均为组织零解的差零解释成分子价值。

沿癌队列v2全部626开发独立生物组和4,967条药物×模型观测，保持原身份、药物ID、资格和剂量窗。面板按原顺序固定：1931/MIRA-1、1036/PLX-4720、1191/Bortezomib、1930/Telomerase Inhibitor IX、1199/Tamoxifen、1091/BMS-536924、1010/Gefitinib、1922/Cediranib。各药各组仍须恰有一个模型，否则停止，不按响应/成绩改样本。

外层5折×3次重复，内层3折。repeat seeds为20261013、20261014、20261015；全部626全局组按组织分层形成划分，各药取覆盖交集。所有八个臂共用每次完整外层/内层划分；稀有组织警告记录保留，未知组织回退明确。每repeat内层seed为repeat_seed+100+outer_fold，沿已验证的分组helper。新版划分、stable-ID列序、完整pair保留政策与旧正式流程不同，旧分数仅作历史证据，不能直接配对相减归因。

只读取已完成原formal准备的开发响应并核验原输入/metadata哈希；本版本不新增置换。阶段5已有9套全流程控制保留为四药工程证据，不宣称本轮做过八药置换，也不从九次推出0.05显著性。

## 八臂与训练内步骤

|臂|候选政策|分子表示|固定输入预算|
|---|---|---|---:|
|tissue_null|无分子候选|训练组织AUC均值，未知组织训练总体均值|0|
|expression_strong|训练内检测过滤、正MAD排序|log2(TPM+1)|2000基因|
|mad_expression|同一fit训练内MAD|log表达|200基因|

共同检测规则为当前训练TPM≥1比例≥10%，限锁定唯一protein_coding Ensembl ID。MAD按log表达正MAD降序、稳定ID并列排序。响应关联按当前训练log表达与连续AUC分别减训练组织均值后的Pearson绝对值排序，要求表达组织内残差平方和>0；精确组织内恒定响应全部分数为零并按ID处理，不能临时换选择规则。每个内层fit从头筛选；同规则三表示在同训练上下文共享全部gene IDs及顺序，强表达2000独立预算，不要求与gene200的哈希一致。少于预算使用全部并记录，不扩大或换筛选器；空候选按同政策组织null回退并保留原因。

先对原TPM构建表示，再进行当前训练尺度和不惩罚组织FWL。完整pair为所有无序基因对的−1/0/+1，不删高tie或常量列；秩仅在选定基因内按原float64精确并列计算平均秩。所有臂输出列按stable-ID统一；目标/scaler/组织均值/alpha_max只能由当前训练行估计。非法缺失、负值及非有限TPM记录失败，不把缺失编码成tie。

EN参数完全沿阶段5：[1,.3,.1,.03,.01]相对alpha_max×l1[.5,1]，max_iter4000、tol.001、cyclic。ratio1为解析零分子端点，每fit重算路径；内层合并OOF原AUC单位RMSE选参，精确并列取网格首项。外层只应用最终训练状态预测，不按外层Spearman换参数。tissue_null只需外层1次fit，无HPO，和分子ENβ=0的预测政策一致。RF原v1保留，本轮为同EN家族的表示比较，不宣称比较了所有可用算法。

## 拟合、存储与资源预算

8药×3repeat×5fold×8臂=960任务。每个分子任务10候选×3内层+1外层=31fits，组织任务1fit；合计8×15×(7×31+1)=26,160 fits，其中840个分子外层及120个组织外层。OOF=4967×3×8=119,208行，不是独立N；每药N不因repeat/arm累加。

根据阶段5真实标签任务约20.5分钟及原formal表达EN成本，初估连续计算4–6小时，加独立任务启动/准备和资源等待；这是预算，运行后只依据完成数和耗时修正。不因效果改科学预算。特征构造和任务峰值受缓存/进程范围影响，不能当作隔离效率基准。

单worker、BLAS1，在数值库导入前设置六个线程环境。每外层任务独立子进程，完成后退出释放资源，父进程串行启动；不同时拟合、验证和统计。每task前要求物理可用内存≥512MiB且系统commit可用≥1GiB，5秒检查一次，最多等待300秒；仍不足则resource_paused退出75，保留全部已完成checkpoint和会话，未启动任务不作模型失败。任务启动后不按短期压力自动kill或改特征/网格；记录worker及进程树RSS/private、系统commit及RAM、CPU/wall、准备/启动/等待开销，不能将并列时间相加重复计数。

异常任务保留traceback、部分完成fit及失败payload；显式同锁resume须核验输入、prepared files、所有已有成功及原失败SHA，原成功不重写。失败内额外fit、资源等待和重试开销另计，不冲抵成功设计。进度只读追加日志/resource CSV，不读取live原子替换metadata。原formal v1及四药诊断lock每次冻结/验收仍验证。

## 冻结统计方案

每药每臂每repeat由完整OOF分别计算Spearman、RMSE、MAE、R²，再取三个repeat的算术平均；不能先平均预测再求ρ，也不能把重复OOF拼为更大N。等权八药macro必须含全部八药，有无定义项保留NA及原因，不能nanmean删除条件。

主比较为response_association_pair_full−expression_strong的Spearman；八药及macro为9项，提供未校正95%及Bonferroni名义家族alpha .05条件区间。原v1主比较不改写；此新版主比较属于结果启发的开发评价。

解释性主要家族为两个规则各自pair−expression200的Spearman，2×(8药+macro)=18项，另给家族18名义条件区间。两个家族分别调整，不宣称合并全研究覆盖。其他22项成对比较中的rank−expression、pair−rank、association−MAD、全部七分子臂−tissue_null、六个gene200臂−expression_strong及其他指标保留未校正描述区间。候选规则×表示的3项差分之差由同draw/同repeat计算，代数相关，不称独立因果效应。

共享全626生物组10,000次bootstrap，seed2026101602；每draw先重新加权、精确重排秩计算每repeat指标，再repeat平均及macro。最低有效比例99%，否则扣留CI并报原因。所有CI条件于当前OOF，无重新选特征/调参/训练，不覆盖完整算法变异或保证CV泛化覆盖；重复划分增加稳定性证据，不增加独立生物样本。

稳定性输出三repeat点效应、正负方向及范围；15个训练折间候选gene/activefeature/sign Jaccard是重叠训练集的描述，不作独立重复推断，空活跃union为NA。候选集合与活跃集合分开，不把gene与pair空间的Jaccard直接当优劣指标；标准化系数不作机制因果解释。逐药保留零分子/警告/回退/失败及预测偏离组织null程度。
