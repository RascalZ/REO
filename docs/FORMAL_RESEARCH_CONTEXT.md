# 正式八药研究的科学背景与证据边界

证据核查日期：2026-10-12。用途：给后续正文、讨论和结果评估提供依据。正式评估已按执行版本 `db31a35` 冻结并启动；本文件不包含八药正式成绩，不修改任何冻结配置。唯一总计划仍为 [RESEARCH_PLAN.md](../RESEARCH_PLAN.md)，正式统计定义见 [FORMAL_ANALYSIS_PROTOCOL.md](FORMAL_ANALYSIS_PROTOCOL.md)。这是定向背景核查，不是系统综述。

## 1. 研究问题和可能的贡献

可审查的问题是：在固定覆盖准入的八种化合物上，训练内构建的相对表达顺序（REO）特征，是否对未知癌细胞系的连续药敏预测提供有用信息；相对于强表达量基线，信息保留、计算成本和迁移表现有何变化。当前主比较预先固定为 REO-EN（200候选基因）与表达-EN（2,000基因）。同预算200基因表达对照帮助解释候选基因范围的作用；RF内的REO与表达比较属于辅助问题。

**REO用于药物反应预测已有先例，训练内筛选和嵌套CV属于研究有效性的要求。** He等在FOLFOX中研究了小型基因对规则；Tercan将kTSP与其他方法用于AML样本的药物反应分类。近年的DrEval已把强基线、严格切分、嵌套调参与跨研究比较纳入公开基准。因此，不能将“使用REO”“增加随机森林”或“修复泄漏”单独写成首次方法创新。[He et al., 2020](https://onlinelibrary.wiley.com/doi/10.1111/cas.14263)，[Tercan, 2026](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0343422)，[Bernett et al., 2026](https://www.nature.com/articles/s41467-026-72903-w)。

本项目可能形成的价值组合是：针对连续端点的明确REO比较问题、可追溯身份和浓度窗口、逐训练折的信息流证据、固定面板完整报告、组织基线和表达强基线、未知身份的跨screen检验，以及公开计算成本与适用边界。这个组合是否足以形成论文，需要正式结果和锁定外验支持；公开仓库和严谨CV本身不证明生物学效用，也不能估计接收概率。

## 3. REO的数学性质与实测稳健性必须分开

本实现的特征是同一样本中 `sign(TPM_i − TPM_j)`，精确相等编码为0；实际计算用大小比较，避免减法溢出。以下是数学推论，不是当前实测的抗批次或跨平台成绩：

|操作或情景|可推导的性质|需要另外检验的事项|
|---|---|---|
|给同一样本的所有基因乘相同正数|所有大小顺序保持|不能据此声称所有实验批次效应都是共同乘数|
|对同一样本的所有基因施加同一严格递增函数，如log2(x+1)|非并列基因的顺序保持|浮点精度、舍入和新增并列必须单独核验；本实现以float64原TPM判定|
|基因分别缩放、中心化、校正，或从counts作不同基因长度校正|顺序没有一般不变性保证|例如10>9，但第一基因乘0.5后5<9。gene-wise z-score不能在REO编码前自动视为安全|
|丢失连续幅度，只保留顺序|提供有界离散表征，也丢失幅度信息|哪个信息损失在药敏预测中重要，是经验问题；编码不变性不意味着高预测性能|
|稀疏表达、dropout或检测下限|可能增多平局并改变可判定对|当前完整bulk TPM的0编码不能解释为缺失值填补；单细胞并非当前主验证|

200基因最多生成19,900个候选对，过滤后实际数按训练折变化。基因对共享基因，且完整顺序具有传递约束；对的数量不等于同等数量的独立生物信息。高维共线条件下，单个EN系数或一次选中的基因对也不能直接解释为耐药机制。应将稳定性、成本和预测性能分别报告，不把稳定性或PPI连接当作机制验证。

## 4. 组织贡献及比较问题的边界

跨组织的药敏关联可以包含真实的组织生物差异。若模型仅识别组织，整体相关值仍可能较好，却未必区分同组织细胞系的反应。DrEval在其评价中分析了组织及均值效应；本项目因此设置训练均值和组织基线，并固定逐药报告。[DrEval](https://www.nature.com/articles/s41467-026-72903-w)。

EN先构建原表达/REO特征，再在训练内标准化和处理组织项；FWL保留训练组织效应，检验的是指定分子表征的额外贡献。这里的组织调整是预测设计，不是因果去混杂结论。正式按组织分层的描述应有独立样本量说明，不将极小组织的相关点估计解释为泛癌种成功。

主比较的REO200与表达2000同时改变表征和候选基因预算，因此估计的是两条预定流程的表现差，而不是孤立的“编码因果效应”。同预算表达200对照使用相同训练MAD规则，可以帮助判断候选基因范围的作用，但二者特征维数仍不同。REO-RF还含训练内监督pair筛选；与表达-RF的辅助比较不能将所有差异都归因于顺序编码。组织处理政策在两个RF间相同，在EN与RF间不同，故不可用跨模型家族的胜负替代主比较。

## 5. 固定面板和计划外验的外推范围

八种化合物由结构支持、身份及覆盖规则锁定，包含研究探针；选择有助于可审查性，却不构成全部药物或全部癌种的随机代表样本。模型逐药学习，当前没有“未知药物”泛化检验；组织分层随机CV也没有“完全未知组织”检验。论文需使用固定面板、未知细胞系、当前测定端点等具体描述。

计划中的CTRP队列通过已知模型及同源关系与GDSC隔离；身份核验按已知公共元数据实施，仍有未知亲缘或误注释的不确定性。两侧表达均来自同一CCLE资源，未来外验估计的是未知身份的跨药敏screen迁移，不能证明跨表达平台稳健性。两库剂量积分窗口和实验流程不同，Spearman也不能消除这些差异改变排序的可能。Xia等的跨研究结果提供了研究动机，但不替本项目修复端点可比性。[Xia et al., 2022](https://doi.org/10.1093/bib/bbab356)。

本项目历史使用过CTRP；当前封存防止本轮调参读数，不将回顾性重构称为前瞻性盲测。内部正式成绩完成后，应保持主药、主比较和外验协议，按冻结程序报告全部八药的外部结果。外部成绩即使良好，也不直接支持患者疗效、治疗推荐或临床可转化性。

## 6. 正式结果完成后的证据判断

|可能观察到的情形|可以支持的解释|不能据此推出|
|---|---|---|
|REO相对强表达对照的差值具有一致方向和有意义的区间|在固定流程、面板、端点及验证场景中存在预测差异|全部REO方法、全部药物、未知组织或患者中同样成立|
|两流程差值区间跨零|当前条件下增量证据不足，区间给出可兼容的差异范围|方法等效；需要事前等效界值和相应分析才能回答等效问题|
|REO200落后于表达2000，接近表达200|候选基因范围可能限制当前REO流程，属于待验证的解释|MAD200一定是唯一原因，或所有REO方法均无用|
|REO EN与REO RF出现不同表现|表示收益可能与学习器及监督pair选择共同有关|以辅助模型替换已冻结主模型，或证明编码普遍有效/无效|
|分子模型与组织基线接近|固定条件下可检测的分子增量有限|组织决定全部耐药因果机制，或其他特征和设计不可能改善|
|内部较好而跨screen迁移有限|需要讨论测定分布、积分窗口和数据域变化|单独归因于REO、模型过拟合或任一批次因素|

若发现边界，进一步研究可以检验更大或药物相关的候选基因范围、不同测量域、统一浓度窗口、简洁kTSP规则或同组织任务。但这些都是另有配置、另有评价的后续实验；不能用正式外层或CTRP成绩指导本轮挑选更好结果。当前MAD200规则安全地在训练内拟合，也可能漏掉低全局变异但药理相关的基因，因此本流程的负结果不能作为REO一般性反证。

后续 `FORMAL_SCIENTIFIC_ASSESSMENT.md` 应引用实际聚合表、配对区间、完整覆盖、收敛/失败台账和资源证据后作出具体判断。目前保留结果方向开放，不形成“已优于基线”或“已无法发表”的结论。
