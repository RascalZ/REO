# 固定八药完成评价后的开发集诊断方案 v1

日期：2026-10-14。此版本在新增诊断计算前冻结。唯一总计划为[`RESEARCH_PLAN.md`](../RESEARCH_PLAN.md)。本协议使用已完成固定八药重复嵌套评价，不修改原v1、四药诊断、八药锁/源/OOF，也不读取任何CTRP响应、外部表达或外验索引。本协议的零解和药物解释是既有开发结果的描述性后续分析，不构成独立确证。

## 决策问题和范围

1. 八药、两候选规则、三种表示及三个重复中，内层RMSE如何在预设的解析零端点与非零路径候选之间选择？零解是否伴随明显的内层路径差异、弱分子偏离、特征/并列结构、响应变异或药物异质性？
2. 八药的结果在排序、误差、组织null增量、零解比例及特征稳定性上有何共同点与不同点？不挑选单一药物来替代固定面板结论。
3. 现有证据不足以把零解归因为唯一机制；后续合成实验只评估指定生成机制是否能在该类模型中产生此类结果。

## 固定分析输入与观测单位

- 八药清单、队列及全部固定结果均取自`config/ordinal_repeated_v1.lock.json`绑定的重复评价。
- 拟合级诊断使用`runs/gdsc2-cancer-v2-fixed8-mad-association-expression-rank-pair-nested5x3-inner3-repeated-v1/outer_fit_audits.jsonl`的内层候选RMSE/外层台账；选定参数、零解/回退和活动特征数使用现有公开汇总；药物×组织响应分解使用同run的开发集响应。OOF、fit事件等原始样本级记录仅本地处理，不发布到公开结果目录。
- 分析范围限定真实标签八药重复结果，permutation_id=0。15个药物内外层上下文用于描述三次重复下的拟合稳定性，不当作独立n做t检验、回归、meta分析或新置信区间。
- 既有主比较、家族条件区间和重复均值沿用已冻结统计输出；本诊断不重新选择统计家族，不为描述性变量增加推断区间。

## 零分子解和路径竞争

- 零分子外层fit定义为：分子弹性网最终全部标准化系数为零、没有回退/solver failure；必须与空候选回退、零`alpha_max`/精确常量目标、求解失败分开计数。
- 对每个药物×模型臂×repeat列出外层fit数、零与非零数、所选参数端点、solver warning/fallback、活动特征及模型偏离同政策组织null的预测量。
- 对每个药物×模型臂×repeat×外折上下文，从十个完整内层OOF网格分数中分别取：零路径分数（`alpha_ratio=1`）和最佳非零路径分数（`alpha_ratio<1`）；报告二者差值“最佳非零RMSE−零端点RMSE”、零/非零胜出或并列的上下文数及描述性分布。该分数参与该上下文的超参数选择，不能解释成未见测试性能或独立检验。
- 对不同外折上下文只报告数、分布和范围，不报告将外折当独立样本的P值或CI。不能以逼出非零解作为科学成功标准。

## 药物与组织异质性描述

- 对每药固定输出响应样本/独立组数、组织数、总体响应均值/标准差/范围、组织内平方和和组织间平方和及其相对总平方和比例。该平方和拆分是本开发样本的描述，非药物机制分解。
- 药物画像同时保留同一个固定主要比较、相对组织null的排序/误差变化、强表达基线、候选规则×表示、三重复方向、零解数、RMSE/MAE和现有区间。不能按此结果划分“适用/不适用药物”再作确证分析。
- 候选gene与active feature稳定性只按既有共享定义汇总；不同特征空间的Jaccard不作跨表示排名，空集合交并比继续NA。
- 所有性能数值沿用既有主报告；增加汇总表仅方便描述，不产生新主假设或外部推断。

## 预定交付和再现性记录

- 本地审计报告`reports/阶段7_零解与药物异质性诊断.md`及其汇总CSV存放在`results/development_diagnostics/`；脚本为`src/analyze_development_diagnostics.py`。
- 报告结果脚本版本、当前研究计划版本、原科学锁/八药结果来源、全部输入文件SHA256、程序版本、运行时间、峰值RSS、输出文件SHA256和各项行数。
- 报告只发布药物/模型/重复聚合值，不复制个体响应、样本ID、OOF预测或fit事件原文。
- 执行验收关注每个分组的任务覆盖、零解总数与已冻结汇总一致、内层分数候选完整和正确区分`alpha_ratio=1`/`<1`、响应方差拆分闭合、无CTRP访问标记、输入文件未更改、所有输出有SHA。验收不看REO是否胜出。

## 判读边界

- 在本轮观察到的八药新版中，零解表示给定的训练数据、候选选择和内层RMSE路径选择下模型回退到同政策组织均值。零解不能证明真实药物无分子效应，非零解不能证明强泛化、可靠或临床价值。
- 基于结果再解释这些观察，会增加假设生成性；后续模型/敏感性方案不得根据该报告中的某一药物成绩修改主规则。若发现实现错误，须以代码和原始检查点证据说明，另立版本并完整保留旧输出。

## 后续阶段预先约束

- 合成检验仅包括在真实模拟前固定的数据生成机制，至少涵盖组织only、弱分子、共同表达幅度和比较/顺序信号；记录机制、维度、种子、信噪比、样本量、候选/表示和指标。它们检验统计生成情形，不验证真实药物的生物机制。
- 组织敏感性先分析既有OOF，新增LOTO外层每次留出完整组织，全部八药与八个已运行臂继续使用；当前训练内三折RMSE政策不变。组织样本量阈值仅定义主展示范围，不根据结果筛组织，小组织仍报告。
- LOTO每个单独被留出的组织中，tissue_null为常数，组内Spearman记NA；不将NA赋零，不计算REO减组织null的组内ρ。配对误差与组内模型ρ分别报告；LOTO合并预测ρ须另标跨折组织校准影响。
- 外验missing/abstain规则、全开发最终拟合过程和CTRP使用须在专门的外验协议中冻结。本文件不开放CTRP，不授权更换药物、规则、终点或利用外验成绩调参。
