# 固定八药重复评价：科学解读与下一决策

日期：2026-10-13。依据冻结执行`5e54a693fe3a047c53b3d9e2dfeb7638ff1b9b43`及全部公开汇总。唯一研究计划为[RESEARCH_PLAN.md](../RESEARCH_PLAN.md)，本文件是结果证据附件，不改变冻结模型、统计、原v1或四药诊断。CTRP继续封存。

**结论：新候选规则改善了当前序表示的部分预测表现，但REO相对强表达的可靠优势仍未建立。** 值得进一步回答候选政策、序表示学习约束、组织以上增量与跨药敏筛选迁移的关系；不以普遍优越的REO新算法、非劣/等效或稳定耐药签名作为当前文章主张。

## 全量完成与推断范围

固定8药×8臂×5外层×3重复、3内层完成960任务、26,160次拟合和119,208条OOF。独立生物组626，4,967条药物×细胞系（生物模型）观测；重复/模型记录不增加独立N。独立审计核验960个独立任务进程、1,440个共同基因上下文、完整成员/响应/源码/聚合绑定；0拟合警告、0回退、0模型失败、0资源暂停、0探针。稀有组织划分提示单列，不把0求解警告写成没有任何提示。

10,000次共享生物组bootstrap，每repeat完整OOF分别评分再平均；Spearman主比较9项和同候选表示18项分别提供名义家族调整条件区间，其余比较/指标描述性。区间不包含重新筛选、调参与训练，不保证算法级CV覆盖；两个家族不提供全研究联合覆盖。方案受历史结果启发，新预冻结不构成独立确证。

## 候选政策影响序表示比较，是可继续检验的结果

|关联候选−MAD候选|八药宏Δρ|描述性条件95%区间|
|---|---:|---|
|表达|+0.005615|[−0.004720,+0.015733]|
|秩|+0.022460|[+0.013048,+0.031944]|

候选政策改变对秩和pair的排序收益较清楚，表达排序改进仍不确定；表达和秩的RMSE改善区间为正，pair的RMSE改进区间跨零，不能笼统称全部指标全面改善。pair−expression的政策差分之差为+0.015393 [+0.003502,+0.027314]，rank−expression为+0.016845 [+0.008459,+0.025335]，均为描述性、代数相关的交互。

这支持“评价序表示不能脱离候选政策”。连续表达响应关联筛选并非表示中立；同gene集合控制了输入基因差异，不能消除选择目标与表示的交互。完整pair与平均秩携带相同序信息，学习函数类和惩罚不同，不能把差值分别归为幅度、维度或共线性的因果贡献。

## 分子增量具有药物异质性，零解与稳定性约束解释

关联pair相对同政策组织null的宏Δρ为+0.056536 [+0.042986,+0.070039]。逐药较清楚的描述性增量集中在Telomerase Inhibitor IX（约+0.2286）、BMS-536924（约+0.1309）和Gefitinib（约+0.0775）；其余逐药区间跨零，Bortezomib点差负。增量也可由表达和秩利用，不能归为REO独有，更不推广为所有药物或临床效用。

## 实测代价与资源范围

## 下一决策：固定外部迁移问题，停止优势导向搜参

继续的具体问题是：响应关联候选下，连续/秩/pair表示的组织以上增量能否在外部药敏筛选中保持，以及成本与成员稳定性是否支持使用完整pair。本轮不足以支持“普遍优越的REO预测算法”；边界型论文的发表价值还需要外部证据与具体解释，不因规范复现就自动成立。

下一gate应准备并另行冻结最终全开发拟合、特征/模型发布与外验统计，保持固定8药和预定角色。至少保留同候选表达200/秩200/pair、强表达及同政策组织参照；MAD历史/消融同样完整保留。不按内部成绩删药、扩大网格或更换规则来挽救优势。当前尚未开始最终拟合或CTRP评分。

CTRP继续封存，用户明确允许进入外验后才执行；共享CCLE表达只能检验跨药敏筛选迁移，不能证实跨表达平台或患者疗效。源数据独立重放、组织留出与剂量窗口可比性仍为待完成限制。无非劣界值、无非劣/等效检验；尤其不能因为主区间下限约−0.0187高于讨论示例−0.02而事后宣布非劣。
