# 两种候选规则 × 三种表达表示：四药诊断协议 v1

日期2026-10-13；用户授权执行。该协议在新拟合前冻结，属于见过正式v1结果后的探索性诊断，不改写v1主比较、不作为新的独立确证。唯一总计划为RESEARCH_PLAN.md。CTRP响应和索引继续封存；当前外验仍是共享CCLE表达的跨药敏screen，不是芯片迁移。

## 科学问题及已有证据

既有OOF可作精确路径分解：REO200−表达2000 = (表达200−表达2000)+(REO200−表达200)。共同组bootstrap须在每次抽样内计算，不得相减CI端点或把分解解释为因果信息损失比例。该事后描述另存，不修改原正式区间。

完整三值pair S_ij=sign(x_i−x_j)与固定基因集平均秩r_i双向确定：r_i=(m+1)/2+0.5Σ_j S_ij，S_ij=sign(r_i−r_j)。但线性rank模型只对应pair权重w_ij=(b_i−b_j)/2，任意pair EN更灵活，惩罚亦不等价。表达→rank之差不是纯幅度信息损失，rank→pair也不是纯维度/共线损失。本实验比较指定学习流程，不估计普适表示上限。

## 固定案例、划分与预算

案例固定BMS-536924(1091)、Telomerase Inhibitor IX(1930)、Gefitinib(1010)、Tamoxifen(1199)。前三者由已有候选范围/表示差模式启发；Tamoxifen是历史弱信号案例，表达200只有11/15零解，不是已知真阴性，改善本身不证明泄漏。固定八药面板及资格队列v2不变。

本轮是小规模诊断：全626开发独立组按组织分层，3折外层×1次、3折内层，seed20261013。各药使用相应覆盖交集，所有臂和置换共用划分。由于新3折与旧5×3不同，以及统一stable-ID特征列序，不能把新旧成绩直接差当作纯方法效果。对照臂在新划分上重拟合。之后的八药重复正式比较另行建运行版本，不根据四药成绩改规则。

两候选规则(MAD、组织调整响应关联)×三表示(log表达200、样本内平均秩200、完整pair)，再加同政策tissue_null，共7臂。Observed及9组置换标签，共10套标签。总计4×3×7×10=840外层任务，六个分子臂每任务10候选×3内层+1外层=31 fits，组织null一fit，总22,440 fits。每药620观察，总2480；完整OOF为2480×7×10=173,600行，不能当独立N。资源按1 worker、BLAS1，RSS采样0.1秒；预测耗时和整任务/进程RSS分开记，进程RSS包含依赖及表达页。根据旧正式EN耗时初估数小时，启动后只用资源和完成数修正ETA，不改科学预算。

## 训练内候选、表示与模型

基础检测：当前训练样本TPM≥1比例≥0.1，限锁定protein_coding稳定ID。MAD规则沿用log2(TPM+1)的MAD>0、降序及stable-ID平局。关联规则仅用当前训练样本：log表达和连续AUC分别减各训练组织均值，候选须组织内表达残差平方和>0，按残差Pearson绝对值降序、stable-ID平局选200；响应残差全零则所有分数0按ID选，不临时换规则。少于200使用全部并记录；没有候选时新版回退同政策tissue_null并记录，不沿用旧版全局均值回退。关联分数仅用于筛选，不把组织残差TPM拿去构建REO。精确常量训练响应用ptp==0识别且均值取该精确常量，避免浮点std约1e-16误判；这项退化数值修复只在新版实施，旧v1不改。

同一候选规则同一fit三个表示必须共享gene IDs和hash，列顺序统一stable-ID。表达为log2(TPM+1)；秩仅对每样本所选基因计算average midrank、原float64精确并列；pair是所有m(m−1)/2个−1/0/+1，保留高tie/训练常量pair。零方差列StandardScaler确定性处理，训练零列系数为0。旧版被过滤的pair另作历史对照，不称与新fullpair逐位相同。缺失、负值、非有限TPM不受支持，必须失败记录。

所有表示构建后再做训练尺度和同政策不惩罚组织FWL。EN延用相对alpha_max比率[1,.3,.1,.03,.01]×l1[.5,1]，4000迭代/tol.001/cyclic；路径每次fit重算；ratio1解析零分子端点，非零不是验收目标。按汇总内层OOF原AUC单位RMSE最小选参，精确同分选网格第一项，不按外层ρ选。训练内筛选/scaler/组织均值/参数不读取验证或测试行。完整pair/秩转换、分子零解与tissue_null一致、改变外层标签不改变特征/预测等用独立合成测试检查。

tissue_null只输出训练组织AUC均值；训练未见组织输出全训练均值；与ENβ=0同政策，无Ridge惩罚，无HPO。全部有限预测/零分子/收敛警告/回退保留。输出每fit实际训练/预测身份、目标hash、genehash、选参、警告及外层活跃feature/系数，不能把标准化系数当因果机制。

## 完整流程置换控制

编号0真实标签，1–9是预定工程null。每药每次用PCG64 SeedSequence([2026101301,drug_id,permutation_id])；按组织、canonical ID排序后在组织内置换独立生物学组的连续响应donor。当前每药每组只有一个model，否则停止，不能擅自逐行打乱亲缘重复。映射在所有fold之前生成一次并保存；同药所有臂共享，训练和评分均使用该套置换标签，所有选基因、路径、内层调参和外层拟合重新执行。singleton组织不动，报告不可交换组/实际身份及数值改变比例。

这是以组织内响应可交换为条件的控制，并不假设全部组织可交换。保留组织差异，因此评价相对tissue_null的增量，不能要求整体ρ为0。9次控制不足以支持0.05置换显著性；只报告全部9点/min/median/max，不报告确证P值，不因偶然正差或Tamoxifen改善宣布泄漏。少数组织不满足交换性/小样本限制必须报告。失败或异常先审计，不按null分数调整规则。

## 统计、解释与停止规则

真实标签每药用完整OOF计算ρ、RMSE、MAE、R²。比较每规则rank−表达、pair−rank、pair−表达，三表示关联−MAD，以及六臂−同政策组织null。正向定义ρ/R²为candidate−reference，RMSE/MAE为reference−candidate。10,000次共享全626组bootstrap(seed2026101302)重算精确秩，95%分位数CI；不足99%有效抽样则扣留CI并记原因。四药等权macro仅案例摘要，不替代八药macro；任何组成无定义则不nanmean。没有重复CV稳定性证据，三个外fold不能作独立试验做t检验。

区间是事后探索、未多重校正、条件于当前OOF，不覆盖重新训练不确定性；不作等效、因果占比或算法普适优势主张。训练样本内候选相关性是筛选依据，不是独立机制证据。真实null/零解比例、预测与组织null差的RMS、活跃feature稳定性及资源必须一起报告。预先不设需要非零、Tamoxifen必须无增益或REO必须获胜的数值门槛；有效性验收看信息流、完整性和复现。解释预设为：新候选改善两表示提示候选限制；表达改善而序表示弱提示当前序学习局限；均无增量则不继续无界搜参。个别案例可提供线索，不能据此删药或改八药主成功标准。

每任务带源/配置/输入hash原子检查点；未处理错误记录failed并停止，显式同版本续跑保留失败。监控只读追加日志，不读正在替换的metadata；Windows原子替换短暂占用做有界重试。v1源/lock/运行不改，Git提交科学协议/代码并建立新lock后才读入拟合；报告/总计划可以后续更新且不进入科学锁。
